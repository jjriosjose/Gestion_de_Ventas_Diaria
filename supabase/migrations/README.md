# Migrations

Estas son las migraciones incrementales registradas durante la fundación v0.2.

El esquema operacional inicial grande se creó directamente en el proyecto remoto antes de comenzar el historial local de migraciones. Por esa razón, estas migraciones **no deben interpretarse como un bootstrap completo de una base vacía**.

La fuente de verdad actual es el proyecto Supabase remoto `Gestion de Ventas Diaria`. Una futura versión debe consolidar un baseline completo antes de crear ambientes adicionales.
